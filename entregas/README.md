# Entregas

Executar `python ferramentas/portal.py package` a partir da raiz para criar um ZIP do portal. O arquivo inclui somente os arquivos de hospedagem. ZIPs não são versionados para evitar duplicação do acervo no Git.

A versão consolidada em 14/11/2026 preserva a última entrega local de 03/11/2026, incluindo o destaque do e-mail administrativo nas duas línguas. Organização do repositório não equivale à atualização da hospedagem ibdcyber.org.br.
