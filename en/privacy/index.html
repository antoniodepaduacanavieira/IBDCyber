Privacy in this prototype

This page describes the features of this demonstration version. It will need review before a production portal is published.

On this page

Project features

The project adds no registration, contact forms, advertising or audience analytics tools. Search uses the content included in the portal itself. This interface does not submit service requests.

Hosting and external websites

The private hosting environment may require authentication and retain technical logs under its own terms. Those functions are separate from the features implemented in this prototype. Instagram, the Senate and other external websites apply their own terms when you visit them.

Before public launch

The Institute will need to specify the responsible parties, purposes, privacy contacts and features actually used. Adding forms, analytics or registrations will require an update to this page before those functions are enabled.
